# hubcontrol-account-mockup

허브컨트롤룸 「정산」 카테고리 시안 (화면 목업 + 개발 명세)

- 온라인 보기: https://kimkc1968.github.io/hubcontrol-account-mockup/
- 파일: `index.html` 한 장 (원본 파일명 `정산_카테고리_시안.html`)
- 우측 하단 「개발 명세 보기」를 누르면 화면별 명세와 「확인 필요」 질문이 열려요.
- 바로 열기 예: `#hqInvoice` (본사 / 세금계산서), `#hqInvoice-b2b`, `#wht-hq` (라이더 / 원천세 신고 · 본사 정산서 기준), `#setting-store`

※ 화면의 금액 · 상점 · 라이더 정보는 모두 더미 데이터입니다.
